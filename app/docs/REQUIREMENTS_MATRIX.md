# Đối chiếu FR01–FR26

“Đã triển khai” là có mã frontend/backend và lưu PostgreSQL thật. “Đạt local” là đã có kiểm thử thực thi trong môi trường bàn giao. Các phần dịch vụ ngoài chưa được tính đạt chỉ vì có adapter hoặc test mock.

| FR   | Chức năng và nơi hiện thực                                | Bằng chứng / trạng thái                                                                                                                                                 |
| ---- | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR01 | Login/logout/refresh/password: auth.js, api.js, Hồ sơ     | Đạt API local, rotation/reuse, JWT signature/issuer/audience/exp, thu hồi; E2E reload/hai tab/logout. Cookie HTTPS production chờ TC36                                  |
| FR02 | Tạo/sửa/khóa/reset/import: admin.js, Tài khoản            | Đạt API, CSV all-or-nothing, password mới/thu hồi; UI tạo/import/reset có API thật                                                                                      |
| FR03 | Nhóm/thành viên/leader: teams.js, Nhóm nghiên cứu         | Đạt transaction cạnh tranh TC05–08, không tham gia chồng/vượt max; E2E tạo nhóm                                                                                         |
| FR04 | Khoa/ngành/lớp/lĩnh vực/đợt: admin.js, Danh mục/Đợt       | Đã triển khai; E2E thêm khoa, tạo đợt/mốc mẫu; backend kiểm tra tham chiếu/min/max/hạn                                                                                  |
| FR05 | Hồ sơ đề tài: topics.js, TopicEditor/Workspace            | Đạt nháp/gửi, form, consent, revision, trạng thái; E2E tạo/gửi/phê duyệt                                                                                                |
| FR06 | Tương tự: similarity.js, Đối chiếu                        | Đạt kỹ thuật với PostgreSQL pg_trgm và TF-IDF; 60 cặp tổng hợp, tách nguồn, hiệu chỉnh trước test. Chưa có bộ nhãn học thuật độc lập                                    |
| FR07 | Xét duyệt: topics.js, hàng chờ/DecisionPanel              | Đạt đúng khoa/snapshot, giải trình cảnh báo, lý do, tạo mốc; E2E cán bộ xem và duyệt                                                                                    |
| FR08 | Kho metadata và danh sách riêng: topicFilter, TopicList   | Đạt scope/API nháp, bộ lọc và E2E tìm kiếm; không trả nội dung riêng ở kho chung                                                                                        |
| FR09 | Mốc/hạn/đầu ra/required: progress.js, cấu hình đợt/Mốc    | Đã triển khai, deadlineVersion và audit; E2E thêm mốc mẫu và mốc thực hiện                                                                                              |
| FR10 | Nhật ký/% tự khai: progress.js, Mốc & tiến độ             | Đạt API/E2E cập nhật thật; 100% không tự đủ nghiệm thu                                                                                                                  |
| FR11 | Upload/nộp/version/late: files.js, progress.js, Documents | Parser và state/finalize/idempotency/race đạt test; Cloudinary transport mock trong test. Upload/download dịch vụ thật chờ credential                                   |
| FR12 | Nhận xét/đánh giá: progress.js, Reviews/Evaluations       | Đạt API đúng GV/bản hiện hành/điều kiện/score độc lập; file trong test dùng transport mock                                                                              |
| FR13 | Thông báo/nhắc hạn: reporting.js, jobs.js                 | Đạt API đọc, polling UI, job chống trùng và scheduler Windows chạy thật. Cleanup Cloudinary thật còn chờ                                                                |
| FR14 | Thống kê/Recharts/CSV: reporting.js, Reports              | Đạt scope/filter/distinct/latest result/CSV formula; E2E tải CSV. Không hard-code số liệu                                                                               |
| FR15 | Lịch sử: audit trong transaction, tab Lịch sử             | Đạt append-only, actor/thời điểm/thao tác/lý do; temporal filter áp dụng cả meta phân trang                                                                             |
| FR16 | Đề nghị hướng dẫn: topics.js, Supervision                 | Đạt API/E2E nhận/từ chối/thu hồi, hash nội dung, hạn; thay học thuật hủy xác nhận cũ                                                                                    |
| FR17 | Phiên bản hồ sơ: snapshot(), Revisions                    | Đạt retry một snapshot, quyết định đúng snapshot, trigger chống ghi đè                                                                                                  |
| FR18 | Thay đổi học thuật/thành viên: topics.js, Requests        | Đạt API consent/chỗ/leader/revision/corpus/snapshot; UI gửi và quyết định có API thật                                                                                   |
| FR19 | Thay giảng viên: Requests/Supervision                     | Đạt API cần GV mới nhận + CB duyệt; assignment cũ kết thúc và GV cũ mất workspace/file                                                                                  |
| FR20 | Đề nghị/quyết định hủy: Requests                          | Đạt pending chưa đóng; approve mới hủy/giải phóng chỗ; UI có gửi/rút/quyết định                                                                                         |
| FR21 | Rời/tái tham gia/lịch sử: permissions.js, grants          | Đạt mất quyền trước duyệt, khoảng nửa mở sau duyệt, không đọc khoảng vắng khi tái tham gia; pagination không lộ số dữ liệu ngoài quyền                                  |
| FR22 | Mở lại mốc: progress.js, Milestones                       | Đạt lý do/revision; chặn nộp lại accepted và đổi quyết định accepted trực tiếp; cạnh tranh nghiệm thu/reopen                                                            |
| FR23 | Sửa sai kết quả: progress.js, Evaluations                 | Đạt CB/phiên bản mới/lý do/giữ bản trước, completed không mở lại                                                                                                        |
| FR24 | Tải file riêng: attachmentAccess/private_download_url     | Đạt kiểm tra quyền và SDK ký TTL 300 giây, no-store. Hết hạn thực tại Cloudinary chưa kiểm chứng                                                                        |
| FR25 | Vai trò/scope: admin.js/permissions.js, Roles             | Đạt CB không tự nâng quyền, admin cuối, scope, admin không tự đọc/chấm/duyệt; E2E sidebar theo quyền                                                                    |
| FR26 | Backup/restore/cleanup: scripts và jobs                   | Database backup/restore thật, ACL local và scheduler/retention đã triển khai. Byte file Cloudinary/restore toàn phần còn chờ credential; cleanup transport có mock test |

Hướng dẫn và ảnh thật: [USER_GUIDE.md](USER_GUIDE.md). Môi trường/ca kiểm tra: [TEST_REPORT.md](TEST_REPORT.md). Các phần ngoài phiên bản đầu (hội đồng, kinh phí, chat/email/SSO, đọc toàn bộ file để so tương tự, tìm đạo văn Internet, API AI) không được thêm vào sản phẩm.
